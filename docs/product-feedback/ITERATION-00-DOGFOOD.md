# Iteration 0 — Dogfood Log

## Purpose

Use this document during the required real 7-day Iteration 0 dogfood period.

Do not turn every idea into immediate scope. Record observations first.

Iteration 0 should expand during dogfood only for:

- security/authorization problems;
- UX blockers that prevent the core promise.
